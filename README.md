## 🕹️ Как пользоваться

### Карточки
- Выбери тему кнопками вверху или воспользуйся поиском
- Нажми на карточку — она перевернётся и покажет ответ
- Прогресс-бар отслеживает, сколько карточек ты уже просмотрел

### Тренировка

| Кнопка | Описание |
|--------|----------|
| ⚡ 15 вопросов | Короткая сессия из всех тем |
| 🎯 30 вопросов | Полноценная сессия из всех тем |
| 🎲 3 вопроса | Кнопка на каждой теме — только карточки этой темы |

**Управление в тренировке:**

| Действие | Телефон | Клавиатура |
|----------|---------|------------|
| Показать ответ | Тап на карточку | Пробел / Enter |
| Знал ✅ | Свайп вправо / кнопка ✓ | → |
| Не знал ❌ | Свайп влево / кнопка ✕ | ← |
| Выйти | Кнопка ✕ вверху | Esc |

Если ответил «не знал» — карточка вернётся в конец очереди. В конце показывается статистика.

### Интервальные повторения

Карточки, которые ты знаешь, будут попадаться реже — а те, что вызывают затруднения, чаще. Прогресс сохраняется между сессиями. Кнопка **↺ Сбросить частоту** выравнивает все карточки обратно.

### Свои карточки
- Кнопка **+** внизу справа → выбери тему, введи вопрос и ответ
- Карточки сохраняются в браузере и остаются после перезагрузки
- Удалить: навести на карточку → кнопка **✕**

## 💾 Хранение данных

Прогресс и пользовательские карточки сохраняются в `localStorage` браузера — у каждого пользователя свои данные локально.
