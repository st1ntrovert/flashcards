# ⚔️ Флэшкарты для собесов

Интерактивный тренажёр для подготовки к собеседованию по автотестированию в стиле Системы из Solo Leveling. Работает в браузере — на телефоне и на компьютере.

## 🌐 Открыть

👉 [Перейти к приложению](https://st1ntrovert.github.io/flashcards)

---

## 🕹️ Как пользоваться

На главном экране две кнопки:

### 📚 База вопросов
- 336 вопросов по 13 темам: автотесты, Python, pytest, Playwright, Pydantic, Docker, Kubernetes, Git, Linux, базы данных, CI/CD, Soft Skills, паттерны проектирования
- Поиск и фильтры по темам
- Нажми на карточку — она перевернётся и покажет ответ
- Кнопка **+** — добавить свою карточку (вопрос + ответ + тема). Свои карточки сохраняются в браузере и участвуют в тренировках

### ⚔️ Тренажёр
Три режима — карточки выбираются случайно из всей базы:

| Режим | Вопросов |
|-------|----------|
| ⚡ Быстрая | 10 |
| 🎯 Обычная | 20 |
| 💀 Серьёзная | 30 |

**Управление в тренировке:**

| Действие | Телефон | Клавиатура |
|----------|---------|------------|
| Показать ответ | Тап на карточку | Пробел / Enter |
| Дальше ✓ | Свайп вправо / кнопка | → |
| Повторить в конце ↺ | Свайп влево / кнопка | ← |
| Выйти | Кнопка ✕ | Esc |

### 🔥 Серия повторений
Проходи хотя бы одну тренировку в день — серия растёт. Пропустишь день — серия сгорает. Счётчик виден на главном экране.

### 🎨 Темы оформления
Кнопка с палитрой в правом верхнем углу — три темы на выбор:
- 🔵 Тень Системы
- 🟣 Монарх Теней
- 🔴 Кровавый Клинок

---

## 💾 Хранение данных

Свои карточки, серия и выбранная тема сохраняются в `localStorage` браузера — у каждого пользователя свои данные локально.

## 🛠️ Технологии

Чистый HTML + CSS + JavaScript, без зависимостей. Один файл `index.html`.
